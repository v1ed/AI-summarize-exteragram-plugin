# AI-summarize-exteragram-plugin

## Features

- Работа в каналах, группах и личных сообщениях
- Пересылка итогового результата в активный чат или в избранное
- Использование MarkDown для разметки сообщений
- Поддержка OpenAI API и Ollama API для работы с LLM
- Автоматическое получение доступных моделей через API
- 3 уровня подробности:
  - краткий
  - нормальный
  - подробный
- 3 режима работы:
  - суммаризация + факт-чекинг (для факт-чекинга лучше всего использовать модели с доступом в интернет)
  - только суммаризация
  - только факт-чекинг
- Поддержка до 2000 сообщений
- Использование имен контактов в пересказах и факт-чекинге
- Использование дат сообщений для лучшей ориентации LLM в потоке
- 18 встроенных персонажей + возможность написания собственного
- Экспериментальный режим
  - редактирование системных промптов
  - интеграция собственного JSON с набором персонажей

## Инструкция по настройке

1. Определиться с сервисом LLM. Лучше всего будет работать [Google AI Studio](https://aistudio.google.com/), но он не у всех и не всегда доступен. Потому в качестве альтернативы можно использовать [OpenRouter](https://openrouter.ai/) или самостоятельно хостить нейросеть через OpenWebUI, LM Studio, etc.
2. Создать API ключ в выбранном сервисе
3. В плагине, в разделе тип API выбрать нужный. Для Google AI Studio и OpenRouter это будет OpenAI-совместимые
4. В API URL вставить ссылку на API
    - Google: `https://generativelanguage.googleapis.com/v1beta/openai/chat/completions`
    - OpenRouter: `https://openrouter.ai/api/v1/chat/completions`
5. Вставить скопированный API ключ в поле "API Key"
6. Выбрать нужную модель
    -  Для бесплатного тарифа Google лучше всего подходит Gemini 2.5 Flash/Flash Lite, Gemini 3 Flash/Flash Lite
7. При необходимости настроить подробность суммаризации, режим работы и максимум сообщений
8. Выбрать любого понравившегося персонажа или создать своего

Готово, плагин готов к использованию

## Инструкция по использованию

1. Перейти в нужный чат
2. Нажать на сообщение, с которого надо будет начинать суммаризацию (идет вниз по истории сообщений)
3. Запустить плагин
4. Дождаться результата

## Примечание

_Бесплатные можели имеют ограничения по количеству запросов в сутки, в час и в минуту. При достижении лимита надо будет немного подождать, прежде чем продолжить пользоваться плагином. Если будет острая необходимость нейрослопать каждый попавшийся чат - можно купить подписку, которая даст больше возможностей, доступ к более продвинутым моделям и моделям с выходом в интернет_
